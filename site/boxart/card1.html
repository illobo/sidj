QUICK REFERENCE CARD · 1/2
Keep this card next to your Commodore 64. (REU) = needs a RAM Expansion Unit. + = hold · , = press in turn, quickly. ⇧ = SHIFT + CRSR ⇩, ⇦ = SHIFT + CRSR ⇨.

LOADING

LOAD"SIDJ",8RETURN, then RUN, RETURN
hold C= at startskip RECOVERED (REU)

EDITING

CRSRmove cursor
SPACEempty: enter last value · filled: take it, play it
SPACE, SPACEnew chain (SONG) · phrase (CHAIN) · table (INSTR)
SPACE + ⇦ ⇨−1 / +1 (note: semitone)
SPACE + ⇧ ⇩±10 hex (note, transpose: ±12)
C= + SPACEcut field
CTRL + SPACEpaste
C= + ⇧ ⇩SONG: page 16 rows / bookmarks · lists: first / last step
C= + ⇦ ⇨INSTR, TABLE, GROOVE: previous / next
0–9 A–Fhex digit, enters from the right
A–G, 0–7note name, octave (note field)
A–Zcommand letter (command field)
F7 · SHIFT + F7undo · redo

MARK · COPY · CLONE

CTRL + C=start mark (SONG, CHAIN, PHRASE, TABLE)
CRSRgrow the block
C=copy block, end mark
C= + SPACEcut block
SPACE + CRSRchange every value in the block
CTRL held: C=, C=, C=mark · column · screen
CTRL held: C=, SPACEclone chain, phrase, instrument or table under the cursor
C=, C=, C=SONG: bookmark on / off
Clone DEEP / SLIM: PROJECT screen, CLONE.

THE FOUR KEYS

SPACEedit (A)
C=second edit (B)
CTRLselect (SELECT)
RETURNplay (START)

RIGHT opens the item under the cursor. FILE: from PROJECT (LOAD / SAVE), CTRL + UP returns. SONG: CTRL + LEFT = live mode.

PLAY · LIVE

RETURNSONG: play from row / stop · elsewhere: this channel · LIVE: queue chain
RETURN, RETURNLIVE: queue at phrase end
CTRL + RETURNplay all / stop · LIVE: queue stop of channel
hold ⇦, RETURNLIVE: queue whole row
CTRL + ⇦ (SONG)live mode on / off

MUTE · SOLO

F1 · F3 · F5mute channel 1 · 2 · 3
hold C=, CTRLmute cursor channel
C= + RETURNsolo (again: all on)

TEMPO · PROJECT, TEMPO

0–9type BPM 40–295
RETURN, RETURN …tap tempo
C= + ⇦ / ⇨ heldnudge −3 % / +3 %
