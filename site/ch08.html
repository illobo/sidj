CHAPTER 8: COMMANDS

A command is a letter and a value xy of two hex digits. Commands go in the phrase's command column or in a table's command columns.

CmdEffectValue
Astart a tabletable number
Bplay this step's note by chancey in 16 (F = always)
Cchord: arpeggio 0, x, y semitones, one per tickxy
Ddelay the noteticks
Esustain and releasex sustain, y release
Ffine tunesigned, 1/128 semitone
Ggroove for this channel from this stepgroove number
Hhop. H0y: next phrase, starting at step y. Hxy: back to step y, x times. HFF: stop the channel.
Kkill: gate off after xy ticks; the release playsticks
Lslide to this notespeed
Mmaster volumey = 0–F
Ofilter type and resonancex: 1 LP, 2 BP, 4 HP, 8 voice 3 off (add them); y: resonance
Ppitch bendsigned, 1/64 semitone per tick
Qhard restart ticks for this note0–F
Rretrigger the note every y ticksx: sustain change per retrigger
Spulse width = value × 1600–FF
Ttempo28–FF = 40–255 BPM, 00–27 = 256–295 BPM
Vvibratox speed, y depth
WSID control byte: waveform, ring, sync, test (SIDJ sets the gate)byte
Xfilter cutoff00–FF
Zrepeat the channel's last command, adding 0 to x to its high digit and 0 to y to its low digit at randomxy
NOTE B, D, G, L, Q and Z work in phrases only.
